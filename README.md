# 🐧 ЛИНУКС — ЭТО ОФИГЕННО

Сайт-манифест свободного человека. Вход — через терминал с логами загрузки,
внутри — аргументы, сравнение с windows (спойлер: 0:6), подбор дистрибутива
и живой bash.

## Смотреть
→ https://SnowyFedora.github.io/linux-manifest/

## Фичи
- 🔐 вход как в tty: логин, пароль, startx
- 📊 sudo diff linux windows — анимированное сравнение
- 💙 кликабельный BSOD, который лечится
- 🎯 подбор дистрибутива за 3 вопроса
- 💻 настоящий\* терминал (попробуй `sudo rm -rf /windows`)

\* почти настоящий. vim всё равно не даст выйти.
