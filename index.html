LINUX(1)РУКОВОДСТВО ПО СВОБОДЕLINUX(1)

NAME

linux — свободная операционная система, которая делает то, что ей говорят

SYNOPSIS

linux [--свобода] [--приватность] [--без-bsod]

DESCRIPTION

  • принадлежит пользователю, а не корпорации
  • обновляется тогда, когда удобно тебе
  • не показывает рекламу (у неё вообще нет рекламы)
  • оживляет железо, которое windows уже списала
  • работает на всём: от часов до суперкомпьютеров

OPTIONS

  • --свобода включена по умолчанию, всегда, отключению не подлежит
  • --телеметрия не предусмотрена конструкцией, даже если очень попросить
  • --кастомизация=всё от курсора до ядра

BUGS

Не обнаружены. Обнаруженные особенности легко лечатся конфигами.

SEE ALSO

windows(1) — работает плохо; bsod(1) — работает слишком часто; tux(7) — просто красавец.
